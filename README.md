## Enable Pages

After merge, set the repo to GitHub Pages:

1. **Actions** (preferred): Settings → Pages → Source: GitHub Actions. The workflow deploys on push to `main`.
2. **Or branch**: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
